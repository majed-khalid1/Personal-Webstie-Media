# Personal Website Media

Images, course notes, and learning materials featured on my personal portfolio website.
I’m Majed Khaled Al-Thobaiti, a software engineering student at the University of Jeddah. I use this repository to share resources from my learning journey and support the projects and courses displayed in my portfolio.

## Contents

- **Course notes** — personal summaries, annotations, and examples recorded while studying.
- **Assignment work** — selected exercises and solutions completed during courses.
- **Images** — project screenshots, course thumbnails, and portfolio visuals.

Open a course document or assignment folder to explore the material. My portfolio course cards link to the relevant resources here.
